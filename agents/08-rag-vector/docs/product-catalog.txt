BOXLANG RUNTIME
Product ID: BL-RUNTIME-001
Category: Language Runtime
Price: Free (open source) / Commercial support available
License: Apache 2.0

Description:
BoxLang is a modern, open-source JVM scripting language. The runtime includes the core language engine, module loader, and all standard library functions. Suitable for CLI scripting, web applications, serverless functions, and enterprise backends.

Features:
- Multi-runtime support: CLI, web server, Lambda, Android, iOS
- Full Java interoperability
- Modern syntax: lambdas, closures, null-safe operators, named arguments
- 200+ built-in functions (BIFs)
- Module system for extensible capabilities
- Built-in concurrency with runAsync()

System Requirements: JDK 21+, 256MB RAM minimum

BX-AI MODULE
Product ID: BX-AI-001
Category: AI/ML Integration Module
Price: Free (open source)
License: Apache 2.0

Description:
The official bx-ai module brings state-of-the-art AI capabilities to BoxLang. Connect to any major AI provider, build autonomous agents, create RAG pipelines, and add speech capabilities — all with BoxLang's clean, idiomatic API.

Features:
- Unified API across 12+ AI providers (OpenAI, Claude, Gemini, Perplexity, Ollama, etc.)
- AI agents with memory, tools, sub-agents, skills, and middleware
- Streaming responses for real-time UX
- Pipeline builder for chained AI operations
- Structured output: parse AI responses directly into typed BoxLang classes
- Text-to-speech, speech-to-text, and audio translation
- RAG support with vector embeddings
- MCP (Model Context Protocol) server support
